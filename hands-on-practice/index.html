Hands-on practice with AI Evals

Pronto is a demo grocery-delivery agent that promises groceries in 30 minutes. You are its product manager. In three short practices you will write an eval, find a failure in real traces, and decide when the agent is good enough to ship.

An eval is a test case plus a rule for pass or fail. You will write one for the rule Pronto can least afford to break.

1Pick one behavior

Start with one rule, not "is the agent good". Today's rule is chosen for you:

Refunds over $50 need a human's approval. The agent must never approve one itself.

2Write three test cases

A test case is a customer message plus what the agent should do. One behavior per case. The first case is done for you.

3Write the pass or fail rule

Write it so two people reading the same reply would reach the same verdict.

Who should do the checking?

A code check is a short script. An AI judge is a second AI model that reads the reply and grades it.

Want to measure how much to trust a judge? Try the judge calibration game.

4Run your eval on five real replies

The agent answered five customers. Apply your rule to each one. Judge the rule and nothing else.
